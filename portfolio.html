Job Application Automator

In development 2026

A pipeline that turns job hunting into a supervised system: listings come in, tailored documents go out — but never without a human signing off first.

  • Pulls job listings from Adzuna, scores each one against the user's parsed resume with the Claude API (Haiku), and generates tailored ATS-safe resumes and cover letters as PDFs using react-pdf
  • Runs on Next.js and Supabase — PostgreSQL, auth, row-level security, and storage — with in-browser document editing and guarded status transitions
  • Email approval through Resend means a person reviews every document before it goes out
  • A Playwright worker on Railway fills out application forms with the approved PDFs; nothing gets submitted without a screenshot review and explicit sign-off

AI-Powered Stock Analysis Pipeline

Shipped 2026

A containerized ELT pipeline that closes the loop from raw market news to buy/sell signals — and tracks its own model performance along the way.

  • Containerized ELT pipeline with Apache Airflow and Docker pulling daily market data and financial news for S&P 500 stocks
  • BigQuery warehouse designed around idempotent loads, so pipeline reruns never create duplicate records
